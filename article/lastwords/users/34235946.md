2025 年 4 月又回归过一次，记得当时好像是翻旧文件时看到了 `osu!`，打开玩了几下，然后又不玩了。

直到 2026 年 4 月，我应该是看到了
[Galaxy Collapse](https://www.bilibili.com/video/BV1g4411L7sd) 这个视频，突发奇想，再一次入坑了 `osu!`。

## 设备

最开始用的是 `ThinkPad T570`（当然是我深度魔改过的，模块化设计好评），鼠标是 `ROCCAT Kone Pure`
（`1000 dpi × 1.0`），用薄膜键盘打的，打多了手疼，所以后来键盘换成了 `Kzzi K75v2`（`TTC 快银轴 v2`）。

后面转板了，最开始用的是家里人画画用的 `高漫 M5`，刷到差不多 `1.8k` 时，在群友的推荐下换了 `Wacom CTL-472`。

用板子确实好打很多，所以自从转板之后，我就原地变身跳跳跳玩家（并且是大跳）了。

映射：`43.42 × 27.14`（比较小，并不建议参考）

## 建议

::: warning

**一定一定一定一定要早学强双和正确的发力方式！！！**

:::

并且我习惯大力敲击键盘，导致我的耐力很差。

我的串和连打都打得很糊，不过跟串的能力其实还不错。（这里推一张切分串）

## 别的一些东西

我的 GitHub 账号：[muwenyan521](https://github.com/muwenyan521)。

我目前收集了非常多谱面（具体来说，有 `37266` 个谱面集、`146945` 张谱面和 `4974` 个 `mapper`），正准备做一个 `PP` 图筛选网站，敬请期待。
大致解释一下步骤：

1. 先从已知 `mapper` 开始，例如 `Sotarks`，以及后来加入的其他 `mapper`、网站榜单 `mapper` 和推荐文档里的 `mapper`。
2. 对每个 `mapper`，查询他作为主 `mapper` 制作的 `Ranked osu!standard` 谱面集。
3. 同时查询他作为 `guest` 参与过的谱面集。
4. 对每个谱面集里的每一张 `Ranked osu!standard` `difficulty`，记录：
   - 谱面 ID
   - 谱面集 ID
   - 难度名
   - 星级、`AR`、`CS`、`OD` 等元数据
   - `host`
   - `guest`
   - `collab` 的所有 `owner`
   - `User tags` 和 `tag votes`
5. 如果发现一张 `difficulty` 还有其他 `guest` 或 `collab mapper`，就把这些 `mapper` 加入待查询列表。
6. 再继续查询新发现的 mapper，循环扩散。
应该会放到 [osu.wangxianming.top](https://osu.wangxianming.top) 这个域名上。

祝大家每天 `PP` 暴涨，早日出群！
