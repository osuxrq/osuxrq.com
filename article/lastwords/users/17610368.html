1ch0出群遗言（越级指南）

#151350CN#26501ch086.48% Lv.97(47%) 4212PP

键鼠天下第一

Apex 猎杀哪里有用数位板的道理，派派没有转手柄，osu 也不会。

osu 本来只是在打别的游戏下播时间顺手玩的但是越玩越能让我感受其中的魅力。有关于越级我就有几个要说的第一就是越级好处是真不少但是别硬甩，能越级的都是跳p。当你越不动了你就要去提升自己的稳定性。

举个例子打 quaver

119PP6.41826438quaverdj TAKA // Sotarks[Ultimate Crescendo] - 82.55% 106x/398x0PP6917129quaverdj TAKA // Monstrata[NiNo's Extra] - 85.36% 514x/1318x

当你 6.48 打不过或者比较吃力的话就可以尝试去练长的 quaver

跳p提高稳定性是相当重要的。Acc 的话就要通过练串去练这个是相辅相成的。

最后的话，是要有一个目标去练。不要觉得手速不行就永远不行。不要因为某些人的话就觉得肯定打不了。只有自己才知道自己能做到。

以我自己的例子来说就是 sendan life

91PP6.2972691Sendan Life先端人生Remo Prototype[CV: Hanamori Yumiri] // Lami[Extra] - 90.62% 355x/1213x

这张图是我两个月以前跟高手mp拿到的当时我就觉得这歌很难我一定要拿下

#41268CN#711wdz95.35% Lv.100(7%) 6659PP

经过快一个月才终于有一次 pass，但是也只是蒙的，而随着游玩的次数上来了慢慢的就开始感觉能打了。时间一定会给出答案的。

5.74803942El Sonidito x Athletic Theme (DitzyFlama Mashup)Hechizeros Band x Koji Kondo // Fuxi66[Nymphe's ZESTY BURRITO]osu!standard

喜欢越级的话可以直接加我 osu，我可以整点比较好越的图来 mp

平均星数5左右就可以开始尝试一下了 欢迎大家来找我mp哦
