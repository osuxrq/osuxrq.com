BenPhantom 的出群遗言

#241344CA#9779Sisyphus99% Lv.100(4%) 3002PP

PS：我在结尾附了我的jumppack，希望跟我不熟的、跟我熟的米娜桑都能获得愉快的jump gaming experience。

当你看到这篇长长的流水账时，我已经离开新人群

timeToTimestamp(time){

let timestamp = Date.parse(new Date(time).toString());

//timestamp = timestamp / 1000;

console.log(time + "的时间戳为："+timestamp);

return timestamp;

}

daysCount := timeToTimestamp( yourWatchTime )- 1721759642

printLn(daysCount) 秒了。

此在在死亡中达到了整全但也就此丧失了此之在。为此，若留有对过去的眷恋者，由于 文字以其对时间永恒性的反叛达成了对此在死亡的超越，因而在文字中寻找真理或渴求名为幸福的媚俗。在其中能够被找到的已经被找到，不能被找到的则持恒地被无果索求着。书写的阐释之人所能做到的即是讲述已被讲述的、强调已被识得的，以此与那索求者其慰藉或回报。在其中寻找真理者则不必费心，因为答案并不在这里。

从注册到现在，历时三个月达到了3000pp。说句实话，再给我一天的游玩时间我就能 够基本吃透三星图，从此打三星毫无难度可言，然而我已经失去了打大部分三星图折磨自己的兴趣和动力。

目前的极大难题在于其中切指的部分，我对此一窍不通。相应的，这个问题也延续到了 我在四星图中所遇到的切指上，从大约2100pp开始便困扰着我直到出群。当然，打四星导致如今AR8.5以下的图我想要读懂已经十分困难了，终于也体会到了大家所调侃的AR综合征——关键问题在于我AR10也不会……

不会切指、能读的AR范围有限。仅此两个问题已经足够判我的死刑，决定了我从开始 接触四星（2100pp左右，由于自己想要精通三星而花了很多工夫，2100也算是一个很晚的时间了）直到3000pp，能打的图都非常的有限——少量连打（主要为简单排列的三连和五连）和跳。

因为我打细碎一些的排列图非常非常的痛苦，所以我也不喜欢打。再加之每次MultiPlay打排列图、连打、串（可能有重合）时，我都完完全全垫底，甚至活都活不下来，毫无悬念，而打跳图时我一般排名会靠前一些。这些种种奠定了我是一个跳批的基础。

关于技术和风格，其实我有很多很多想说的，有很多很多大家也许会想知道的。但我即 刻能想到的或许不多。随便列几条罢:

  避免只关注combo，而是同时关注accuracy以及combo甚至特别关注accuracy

  避免经常性的越级打超出水平极大范围的图，保持个人数据中良好的acc 背景暗度80%以上，集中注意力读图

  尽量关闭背景视频以及谱面自带皮肤

  （主观建议）多用透明皮肤，对于叠键的阅读较为理想

  （主观建议且仅限OD8.5以下）高acc秘诀: 少打你打不了acc的图,或尽可能地打acc 在搜索中使用jump、aim、pack、flow、stream、training、practice 等关键词寻找练习图

  提高流畅性以及好的游戏体验请多多询问CYCLC管理

  多水群，大家的意见可以将信将疑，但多借鉴一定是好事

  调整适合自己的不会疼痛且能够稳定的握笔姿势并加以持之以恒的稳固

  数位板的映射在合适的范围内（对我来讲约是30-35mm）

  保持一个良好的作息

  使用小键盘而非薄膜键盘或大键盘

  在感到疼痛时及时停下。

我还想额外强调一点。不要什么都在群里问。很多写代码的人、玩galgame的人、搞电 脑的人以及很多某一领域的精通者都会明白一句话，“百度是个好东西”。有一些非常之简单的问题，明明可以靠网络搜索来解决，就不必浪费他人的时间来解释。尤其是在osu.ppy.sh官网提供了非常好、非常详细的介绍文档的前提下，更没有理由在没用经过任何努力的情况下询问愚蠢的问题。根据朋霍费尔的书摘，“十分肯定的是，愚蠢是一种道德上的缺陷，而不是一种理智上的缺陷。有些人智力高超，但却是蠢人，还有些人智力低下，但绝非蠢人。”

也是写上小作文了呀。群里有很多很好的朋友：fufuOwO、Touma（跟我一起出群啦）、团子、Touhu老师、Minty、猫猫、hx123yx、killbusark 牢大、miklelf 小姐、ciallo 大神、Nikey、csafsd、2ky 大神、coldfish 大神……等等等等，我都数不过来了。大家都是很好的人，希望没来进阶的速来进阶重逢！（soon）
