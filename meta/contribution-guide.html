贡献指南

欢迎为本站提交内容修改或补充。 本站使用 VuePress 构建，内容使用 Markdown 编写。

基本步骤

若要贡献，请遵循下列步骤。

  1. 在网站中点击右上角 GitHub 跳转至仓库
  2. Fork 仓库并克隆git clone到本地
  3. 下载安装 Node.js。
  4. 运行 npm install 安装依赖
  5. 修改或新增页面
  6. 本地预览、验证您的修改或新增效果
  7. 提交更改并发起 Pull Request

管理组须知

虽然管理组有直接修改的权限，但为避免冲突，请通过 Pull Request 提交更改，避免直接修改仓库。

如何创建页面

新建 Markdown 文件

在合适的文件夹创建合适的.md文件。文件路径将直接决定页面URL。文件名为“README.md”则为该目录。

  • /folder/README.md → /folder/
  • /folder/page.md → /folder/page

页面结构：

# 页面标题
正文内容
过时的信息

然后在文件中添加 frontmatter：

---
title: 群赛
lang: zh-CN
---

提示

无需添加 frontmatter，但添加也无妨。

正文使用 Markdown 语法，不再使用一级标题。

如果不会 Markdown，请自行搜索 Markdown 语法.

参考资料：

  • Markdown 基本语法
  • VuePress 默认主题的 Markdown 容器
  • VuePress Markdown

更新导航（可选）

如果增加、删除或重命名了文件，并且有必要添加到导航栏或边栏中， 在 .vuepress/config.ts 中更新导航栏和侧边栏配置。

参考文档：

VuePress 官方文档

导航栏配置侧边栏配置主配置

本地实时查看效果

提示

推荐使用 VS Code 进行开发。

启动开发服务器：

npm install    # 安装依赖
npm run docs:dev  # 启动预览

点击显示的本地链接即可查看效果。如不熟悉 VuePress，请务必在提交 Pull Request 前检查。

这个模块已经和腾讯表格联动：填写表格即可完成添加。

谱面推荐和出群遗言

使用了项目中的 Beatmap.vue、Score.vue、Player.vue 模块。

可以通过调用雨沐机器人 (YumuBot) 的特殊指令，来快速获取需要填写的属性。

注意事项

  • 标准化...
    • 尽量在中文和英文、中文和数字之间添加空格。比如 雨沐机器人 (YumuBot)。
    • 可以使用正则表达式来批量替换。
    • 数字和字母之间、它们和标点符号之间无需添加空格。比如 100pp。
    • 如果使用英文括号，括号外部如果是中文，则需要在中文和括号之间添加空格。比如 (这个例子)。
    • 特殊字符视作英文括号。比如上面例子中用的反引号 `。
  • 搬运出群遗言时，
    • 在前面用 yaml 语法写一个出群日期，这样可以方便排序功能统计。
    • 如果里面附带了玩家的个人信息，可以通过 !gu 来标准化。
    • 如果附带了最好成绩的截图，并且可以辨认其中部分信息，只取前 10 个来做 !gx。
    • 如果成绩还是太多，可以酌量删去。
  • 搬运谱面推荐时，
    • 一个页面中别用超过 400 个 Score.vue 模块即可。但是大多数推荐都达不到这个量级。

展示谱面

可以使用指令 !gw 快速获取。

参数可以填多个谱面编号 (BID)，可以按逗号分隔，数量如果多于 5 个，则会打包成文件发送。

以下是需要写在文档里的属性和示例：

4.91268419Shadow Corps
<Beatmap
  bid=1268419
  sid=600246
  preview="Yousei Teikoku - Shadow Corps (Lune Hivernale) [Insane]"
  star=4.90
  max=1597
/>

机器人会给您提供前 5-6 个属性。

注意，自行构建时，需要按照 艺术家 - 曲名 ( 谱师 ) [ 难度名 ] 的格式填写。

color 为自定义属性，可以修改这个组件的最左侧颜色，与星级颜色区分开（方便归类谱面）

以下是示例。您可以自行尝试。

4.91268419Shadow Corps
<Beatmap
  bid=1268419
  sid=600246
  preview="Yousei Teikoku - Shadow Corps (Lune Hivernale) [Insane]"
  star=4.90
  max=1597
  disabled=true
  color="#92e"
  alias="影之军团"
/>
关于别名：alias

别名系统已经升级成数据库形式。

如果你要更新别名数据库，可以去 YumuBot 输入 !ao。

此时机器人会给你发送一个 aliasDB.json。将其放在 根目录/assets/ 下即可完成别名导入。

目前的别名位置逻辑：您输入的 alias=内容 > 别名库中含有的别名 > unicode=内容

以下描述废弃。当然你也可以帮助机器人来完善别名库。方法：

  • !aw bid：审阅式导入。只能导入一个结果，但是可以帮助您快速对比谱面的元数据。
    • 机器人会向您展示谱面的元数据。
      • 可以用它在 bilibili、其他 AI 智能体上搜索或尝试翻译可能的别名。
      • 节奏大师的曲目大概率会有一个中文名。使用它。
    • 之后，您再次输入的内容会被当做别名保存。注意！
    • 想要取消，可以输入 OK 或者等 60 秒。
  • !aa bid/title，alias：一对一导入。此时分隔符可以输入逗号、等号等。
    • 机器人会向您确认别名导入的结果。
    • 如果提示不匹配。或者别名中含有逗号或者等号这样的分隔符，请使用双引号包裹住它。
    • 如果别名中本身含有双引号，请尝试去掉它或者改成英文单引号（不支持）。
    • 如果再输入 OK 或者等 60 秒，这一批别名会录入数据库。

机器人会在谱面有非 ASCII 的原标题时，提供给您 alias 字段。您可以尽量标准化它，来确保简体中文浏览者能马上理解歌曲标题的含义：

  • 如果原标题是日文汉字占主导的标题，或是别名含有舶来语（通常原标题就是那个英语单词或者法语单词等），可以尝试翻译它。
    • 比如：モノクロ・インザナイト -> Monochrome In the Night -> 夜色中的单色
    • 可以丢给 AI 来翻译。它们比翻译软件做得好。
  • 如果原标题是自造语言或者无意义的形声词，可以保持原样。
    • 比如：La gis sulva za Celow
    • 比如：チュルリラ・チュルリラ・ダッダッダ！ 一般不翻译成 啾噜哩啦·啾噜哩啦·哒哒哒！，但是大家都叫它 啾噜哩啦 或者它的出处 告密教室。
  • 如果原标题是英文单词组合，或是比较无意义的音游曲标题，可以直接删掉 alias。
  • 如果原标题完全是简体中文，直接保留即可。
  • 如果原标题含有繁体中文，可以尽量改成简体中文。
    • 比如：下一站．與你 -> 下一站．与你
  • 如果原标题中有 (TV Size) 这样的附加标签，可以酌情删去。
  • 有特殊或者重大意义或者特别出名的谱面，可以直接使用它最容易辨认的那个别名，
    • 比如：Kobito of the Shining Needle ~ Little Princess -> 小公主
    • 比如：Silent Voyage to Eternity -> 鼠之力
    • 比如：Emotional Skyscraper ~ World's End -> 2012

修改别名不强求。如果没有更好的标准化方法，可以留着或者保持原样。

关于无法下载：disabled

如果谱面无法下载，机器人会提供 disabled=true 选项。此时，谱面预览会变黑，也不允许玩家直接点击访问谱面页。

您也可以在自己构建一个不存在的谱面（比如已经删除，但是小夜还能下载）时，手动填写 disabled=true。

如果谱面被版权，但是机器人没有提供 disabled=true 时，你也可以补上。

展示谱面集

可以使用指令 !gy 快速获取。

参数可以填多个谱面编号 (SID)，可以按逗号分隔，数量如果多于 5 个，则会打包成文件发送。

以下是需要写在文档里的属性和示例：

7.1s2260829Fragrance (XinBai-HW Remix)
<Beatmap
  sid=2260829
  preview="Tsukasa (Arte Refact) - Fragrance (XinBai-HW Remix) (MeAqua tete)"
  star=7.13
  difficulties=[2.44,3.84,4.68,5.73,7.08,7.13]
/>

机器人会给您提供前 4 个属性。

前面提到的附加属性 disabled 和 color 也能用。

展示玩家

可以使用指令 !gu 快速获取。

参数可以填单个玩家名，或 id=...，或 @。

以下是需要写在文档里的属性和示例：

#6570CN#0Sayori_yui98.41% Lv.101(41%) 7532PP
<Player 
  id=7183040
  name="Sayori_yui"
  country=0
  global=6570
  from="CN"
  accuracy=98.41
  level=101
  progress=41
  performance=7532
/>

展示成绩

可以使用指令 !gx 快速生成。

参数需要填写 1-5 个：谱面编号 (BID)、准确率 (0-10000)、连击数、评级 (SS-D)、表现分 (PP)、模组 (Mods)。

!gx 658127 99.06 2402 a 727

以下是需要写在文档里的属性和示例：

727PP7.1658127Blue Zenith
<Score
  bid=658127
  sid=292301
  preview="xi - Blue Zenith (Asphyxia) [FOUR DIMENSIONS]"
  star=7.17
  max=2402
  mode="o"
  accuracy=99.06
  combo=2364
  rank="a"
  performance=727
/>

如果对应的成绩没有可用的表现分，可以在 performance 的位置填入 "..." 的字符串，PP 字样会自动消失。
